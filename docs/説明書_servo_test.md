# 説明書 — servo_test.py（ステアリングサーボ動作確認・調整）

対象: 自動車整備専門学校 3年生
所要時間: フェーズ1 約10分／フェーズ2 約20〜30分（1台あたり）
使うもの: 車両、クロームブック、この説明書、個体値カルテ、分度器（フェーズ2）

---

## 1. このテストでやること

このテストは2つのフェーズに分かれています。

- **フェーズ1（合否チェック）**: 組み付けたステアリングが「制御に使える状態か」を7項目で判定する
- **フェーズ2（調整・セッティング）**: 「中立＝タイヤがまっすぐ」を作り込み、切れ角のセッティングを決めて記録する

**フェーズ1が全項目合格になるまで、フェーズ2に進んではいけません。** ガタや引っかかりが残ったまま中立を合わせても、無意味だからです。

## 2. サーボの仕組み（1分でわかる）

ステアリングサーボは「言われた角度まで回って、そこで止まるモーター」です。ラズパイは PWM という電気信号でサーボに角度を伝えます。信号の値（%）と角度の関係はこうなっています。

```
   9.50%          10.50%          11.50%
  左いっぱい ←――――  中立  ――――→ 右いっぱい
```

10.50%はサーボ規格の中立（パルス幅1.5ms）で、**サーボの可動域のちょうど中心** です。ここを基準に使うと、左右の切れ角が対称に働きます。

問題は、**「10.00%＝タイヤがまっすぐ」とは限らない** ことです。サーボの個体差、サーボホーンの取り付け角、リンケージ（ロッド）の長さのわずかな違いで、車ごとに「本当の中立」はズレています。このズレを見つけて合わせるのがフェーズ2です。

> **もっと詳しく**: 信号の実体は電圧の高さではなく「パルスの幅（時間）」です。電圧は3.3Vか0Vの2値しかなく、サーボは1周期の中で電圧がONになっている時間の長さを読んで角度を決めます。「10.00%」は周期に対するON時間の割合（デューティ比）で、70Hz（1周期14.3ms）なら約1.43msのパルス幅にあたります。**同じ%でも周波数が変わるとパルス幅が変わってしまう** ので、設定の周波数は絶対に変えないこと。

## 3. 作業前チェックリスト

作業を始める前に、声に出して確認してください。

- [ ] 車体はスタンドや台の上にあり、**タイヤが自由に動ける**（前輪が物に触れていない）
- [ ] タイヤの動く範囲に **手・指・ケーブルがない**
- [ ] バッテリーが接続され、ESCの電源スイッチが入っている（サーボの電気はESCから来ています）
- [ ] クロームブックが実習用Wi-Fiにつながっている

**安心してよいこと**: このプログラムはハンドルの線にしか信号を出しません。アクセルの線には何も出さないので、**モーターが回って走り出すことは絶対にありません**。

## 4. 起動のしかた

1. SSHでこの車のラズパイに接続する
2. 次のコマンドを打って Enter:

```
python3 servo_test.py
```

3. クロームブックのブラウザで、自分の車のアドレスを開く:

```
http://（自分の車のIPアドレス）:8080
```

4. 画面の上に **「実機モード」** と緑色で表示されていることを確認する

## 5. フェーズ1: 組付け後の合否チェック（7項目）

「スイープ」ボタンを押すと、左いっぱい→右いっぱい→中立を約3秒かけて自動でゆっくり1往復します。項目2・4・5・7はスイープを使うと観察しやすくなります。

| # | 確認項目 | やり方 | 合格基準 |
|---|---|---|---|
| 1 | 信号が届いている | 「● 中立」を押す | サーボが反応する（音・わずかな動き） |
| 2 | 左右に動く | スイープを押してタイヤを観察 | 左右いっぱいまでなめらかに動く |
| 3 | 向きが正しい | 車の**後ろ**から見て「◀ 左いっぱい」を押す | 左に切れる |
| 4 | 端で唸らない | 左右いっぱいで数秒保持し、音を聞く | 「ジジジ」という唸りがない |
| 5 | 左右対称に切れる | スイープ中、左右の切れ角を見比べる | 明らかな差がない |
| 6 | ガタがない | 中立のままタイヤを手で軽く左右に揺する | 大きな遊びがない |
| 7 | 繰り返し精度 | 左→中立→右→中立を数回繰り返す | 中立のたびに同じ位置に戻る |

**不合格だったときの見かた**

| 不合格項目 | 原因の候補と対処 |
|---|---|
| 3（向きが逆） | サーボ取付向きの個体差。故障ではない。プログラム設定 `HANDORU_GYAKU = False` を `True` に（教員に相談） |
| 4（端で唸る） | リンケージやナックルが機械限界に当たり、サーボが無理に押し続けている。**放置するとサーボが焼損する**。リンケージの取り回しを確認。直らない場合は教員へ（切れ角幅の設定調整が必要な可能性） |
| 5（左右非対称） | サーボホーンの取付角のズレ、リンケージ長の左右差。フェーズ2の手順で直る場合が多い |
| 6・7（ガタ・戻り不良） | ホーンのビス緩み、リンケージのボールエンド摩耗、取付ネジの緩み。増し締め・部品確認 |

**7項目すべて合格したらフェーズ2へ。**

## 6. フェーズ2: 調整・セッティング

### 6-1. 中立出し — 必ずこの順番で

ここが本番です。**順番を守ることが大切です。ソフトの調整から始めてはいけません。**

**手順0: ソフト調整をゼロに戻す**
「基準(10.50)に戻す」ボタンを押します。ハード調整は、ソフト補正がない素の状態で行うのが原則です（前回の調整値が残っていると、ハードのズレが見えなくなります）。

**手順1: 中立ボタンを押して、タイヤのズレを見る**
「● 中立」を押した状態で、車の真上と正面からタイヤを見ます。まっすぐな棒や定規をタイヤに当てて確認します。

**手順2: まずハードウェアで合わせる（ここが実習の核心）**

1. **サーボホーンの取り付け角**: ホーンを一度外し、中立信号が出ている状態で、できるだけ直角になる歯（スプライン）位置に付け直す。歯の刻みは十数度あるので、ピッタリにはなりません。いちばん近い歯でOK
2. **リンケージ（ロッド）の長さ**: ターンバックルを回して微調整し、タイヤがまっすぐになるようにする
3. スイープを1回流し、左右の切れ角バランスも再確認する

> **なぜハード優先？** ソフトの数字はいくらでもズレを隠せます。しかし隠したズレ（ホーンの斜め付け、左右非対称）は、走行中の切れ角の左右差やガタとなって必ず現れます。実際の自動車整備でも同じで、アライメントの狂いをハンドル位置でごまかしてはいけません。

**手順3: 最後の一押しだけソフトで合わせる**
「中立の微調整」ボタン（±0.01 / ±0.05）で、タイヤを見ながらまっすぐに追い込みます。合格の目安: **調整式ロッドの車は±0.10以内／標準の固定ロッドの車は±0.30以内**（固定ロッドはホーンの歯1枚ぶんの残差をソフトで拾うため）。大きく超えるようなら手順2（ホーンの歯の選び直し）に戻ってください。

**手順4: 保存する**
「**この中立値を保存する**」ボタンを **必ず押します**。押さずに終了すると調整が消えます。値は `kuruma_settei.json` に保存され、今後のすべてのプログラム（スロットルテスト・本番レース）がこの値を使います。画面の値をカルテにも記入します。

### 6-2. 切れ角のセッティング（可変アーム）

この車はステアリングのアーム穴位置（アーム長）を変えることで、同じ信号でもタイヤの切れ角を変えられます。

- アームを**長く**: 切れ角が大きい＝修正が強く効くが、過敏で蛇行しやすい
- アームを**短く**: 切れ角が小さい＝直進が安定するが、大きなズレから戻りにくい

手順:

1. アーム穴位置を決めて組み付ける
2. **重要: アーム位置を変えたら中立もズレます。必ず 6-1 をやり直すこと**（順番は「アーム決定 → 中立出し」）
3. 左右いっぱいでの実際のタイヤ切れ角を分度器で測り、カルテに記録する

### 6-3. %→角度の実測（発展・任意）

「任意の信号を出す」欄に 9.25 / 9.50 / 9.75 / 10.00 / 10.25 / 10.50 / 10.75 などを順に入力し、それぞれの実舵角を分度器で測ってグラフにしてみましょう。きれいな直線にならないこと、左右で対称にならないことが観察できるはずです。それがリンケージという機構の個性です。

## 7. こんなときは（トラブル表）

| 症状 | 確認すること |
|---|---|
| 画面に「テストモード」と出る | pigpiod が動いていない。ターミナルで `sudo systemctl start pigpiod` を実行してからプログラムを再起動 |
| ボタンを押してもタイヤが動かない | ターミナルに「実機モード」と出て信号値も動いているなら、犯人はハード側。順に: ①ホーン軸を指でそっと回す（抵抗があれば給電OK・スカスカなら電源/信号が未達）②コネクタ総点検＝サーボ3ピン・GPIO13側・ESCのBEC側を一度抜いて挿し直す（**作業後の半抜けが最多**）③テスターで赤-黒間5Vとラズパイ-ESC間のGND導通を確認 |
| タイヤが小刻みに震える | サーボへの電源不足かサーボの劣化。バッテリーを充電してから再確認し、直らなければ教員へ |
| 左右が逆に動く | フェーズ1の3番参照（HANDORU_GYAKU の設定） |
| 端で「ジジジ」と唸る | フェーズ1の4番参照。放置禁止（サーボ焼損） |
| 動きがガクガクする・引っかかる | リンケージの曲がり、ホーンとシャーシの干渉を目視確認 |
