# 説明書 — throttle_test.py（スロットル学習・接続テスト）

対象: 自動車整備専門学校 3年生
所要時間: フェーズ1（学習）約15分／フェーズ2（動作確認）約10分（1台あたり）
使うもの: 車両、車体スタンド（または台）、クロームブック、この説明書、個体値カルテ

---

## 0. 最初に読むこと【最重要】

**このプログラムはモーターを回します。** servo_test と違い、タイヤが回転します。

- 必ず **車体をスタンドに載せ、4輪すべてを床から浮かせてから** 操作すること
- 回転部（タイヤ・ギア・シャフト・ベルト）に **手・指・髪・ケーブルを絶対に近づけない** こと
- 万一に備えて、車の進行方向に人や物がないことも確認すること

プログラム側にも安全装置が入っています（前進は微速のみ・10秒で自動停止、ブレーキは1秒で自動終了、学習モードの可動範囲制限、終了時は必ず停止信号）。**しかし安全装置はお守りではありません。ホイールを浮かせるのはあなたの仕事です。**

## 1. このテストでやること — 順番が大事

1. **フェーズ1: スロットル学習** — この車の「N・D点・R点」を測って保存する
2. **フェーズ2: 動作確認** — 学習した値で、前進・回転方向・ブレーキが正しく働くかチェックする

**学習が先です。** 学習前の車は「どこからアクセルがつながるか」をプログラムが知らないため、前進ボタンを押しても回らないことがあります（実測で確認済みの現象です）。学習を済ませると、微速前進は「D点を確実に越えた位置」を出すようになり、動作確認が意味を持ちます。

## 2. ESCの仕組み — ATのシフトレンジで考える

ESC（Electronic Speed Controller）は、**アクセルペダルとモーターの間にある電子制御ユニット** です。ラズパイからのPWM信号（%）を受け取り、モーターに流す電流を決めます。

信号の値とESCの反応は、ATのシフトレンジにたとえるとこうなります。

```
 前進側 ←―――――――――――――――――――――→ 後退側

 ――――┼――――――┼――――――――――┼――――――┼――――
    全開      D点    ← N(停止)ゾーン →   R点
             前進が             後退が
             つながる境界        つながる境界
```

- **Nゾーン**: この範囲の信号なら駆動がつながらず、タイヤは止まったまま。**Nは1点ではなく幅のあるゾーン** です（ESCが細かい信号の揺れを無視する「不感帯」のため）
- **D点**: Nゾーンの前進側の端。ここを越えると駆動がつながり、タイヤが前進方向に回り始める
- **R点**: 後退側の端。ここを越えると後退方向に回り始める

そして重要なこと：**D点・R点・Nゾーンの幅は、ESCの個体ごとに違います**。だから車ごとに測って記録する必要があります。これが「スロットル学習」です。学習した値はこう使われます。

- **N =（D点＋R点）÷2**（ゾーンのど真ん中）→ 停止・待機はここ。多少ESCの認識がズレても確実に止まる
- **本番のアクセル** → アクセル0%＝N、1%以上＝**D点を越えた位置から** 駆動を割り付ける。踏んだ瞬間に必ず反応する「遊びゼロのアクセル」になる

**知っておくべきESCのクセ2つ:**

1. **信号がないとピーピー鳴く**: 信号線に何も来ていないと警告音を出し続けます。プログラムを起動して信号が届くと止まります。つまり **「音が止まった＝配線と信号はOK」**。プログラム終了後にまた鳴くのは正常です
2. **ブレーキと後退は同じ側で、いきなり後退はできない**: R側の信号は、1回目は「ブレーキ」として扱われます。後退モードに入るには「R側 → N → もう一度R側」という順番が必要です（実車でRに入れる前に一度止まるのと同じ発想の安全仕様）。ブレーキボタンが「1秒だけで自動終了」なのも、R点の学習開始時にプログラムが自動で「切替操作」を行うのも、この仕様のためです

> **この車両構成の向きについて**: 実測により「低い%＝前進、高い%＝後退」です（D点はNより低い側）。ESCとモーターの組み合わせで決まるもので、全車共通のはずです。

## 3. 作業前チェックリスト

声に出して確認してください。

- [ ] **車体はスタンドの上、4輪すべてが床から浮いている**
- [ ] タイヤを手で回してみて、自由に回る（スタンドに接触していない）
- [ ] 回転部の近くに手・物・ケーブルがない
- [ ] バッテリーが接続され、ESCの電源スイッチが入っている
- [ ] ESCがピーピー鳴いている（＝信号待ちの状態。正常です）

## 4. 起動のしかた

1. SSHでこの車のラズパイに接続する
2. `python3 throttle_test.py` を実行
3. **ESCのピーピー音が止まることを確認**（＝配線と信号のチェック合格）
4. ブラウザで `http://（自分の車のIPアドレス）:8080` を開く
5. 「実機モード」表示を確認する

## 5. フェーズ1: スロットル学習（案内つき）

学習はボタン1つで始まり、画面の案内に従って進めます。**出力を動かすのはあなた自身** なので、自分のペースでゆっくり探せます。仕事は「◀▶で少しずつ動かす → タイヤが回り始めたら『回り始めた！』を押す」の繰り返しです（前進で1回、後退で1回）。

### 手順

1. 「**スロットル学習を開始**」を押す（確認が出るので、4輪が浮いていることを確かめてOK）
2. **［学習中 1/2: 前進の学習］** 案内が出たら、「◀ -0.01」を押して出力を少しずつ下げていく（最初は「◀◀ -0.05」で近づけ、怪しくなったら -0.01 で刻むと速い）。タイヤが **前進方向にじわっと回り始めたら**「**回り始めた！**」を押す → D点が記録されます
3. **［切替中］** プログラムが自動で後退モードへの切替を行います。**そのまま2秒ほど待つ**（タイヤがピクッと動くことがあります）
4. **［学習中 2/2: 後退の学習］** 今度は「+0.01 ▶」で少しずつ上げていく。**後退方向に回り始めたら**「回り始めた！」を押す → R点が記録されます
5. **Nが「(D点+R点)÷2」で自動計算され、すべて保存** されて学習完了です

途中でやめたいときは「中止」（保存されません）。

### 学習結果の記入

画面の「N・D点・R点・停止ゾーン幅」をカルテに記入します。やり直したいときは「学習をやり直す」でD点・R点を消去して最初からできます。

> **探し方のコツ**: 回り始めの瞬間は音でも分かります（モーターのかすかな唸り）。行き過ぎたと思ったら反対のボタンで戻し、「止まる↔回る」の境目を1〜2往復して確かめてから「回り始めた！」を押すと正確です。

> **なぜNを手で決めずに計算で決めるのか**: 「止まっているからここでいい」という目分量は人によってバラつきます。「回り始める瞬間」は誰が測ってもほぼ同じ値になるので、境界を測ってNを計算で導く方が正確で再現性が高いのです。測定の考え方として覚えておいてください。

## 6. フェーズ2: 動作確認（合否チェック 5項目）

学習が終わったら、「スロットル操作」のボタンで **微速前進 → ブレーキ** の順に動作を確認します。

| # | 確認項目 | やり方 | 合格基準 |
|---|---|---|---|
| 1 | Nで止まる | 「● N（停止）」を押し、手でタイヤを軽く回す | 止まっている・ブレーキの抵抗もない |
| 2 | 前進で回る | 「▲ 微速前進」を押す | タイヤが回り始める（学習後の微速はD点より0.20%前進側） |
| 3 | 回転方向が正しい | 回っているタイヤを横から見る | **前進方向** に回っている |
| 4 | ブレーキが効く | 前進中に「■ ブレーキ」を押す | 惰性より明らかに早く止まり、1秒後にNへ戻る |
| 5 | 異音・異臭がない | 前進中に耳と鼻で確認 | ガリガリ音・焦げ臭さがない |

**不合格だったときの見かた**

| 不合格項目 | 原因の候補と対処 |
|---|---|
| 1（じわ回りする） | 学習をやり直す。じわ回りの向きに注目（前進方向ならD点のボタンを押すのが早すぎ、後退方向ならR点が早すぎ） |
| 2（回らない） | バッテリー残量／ESC電源スイッチ／学習値が正しく保存されたか（画面のD点表示が「未学習」になっていないか） |
| 3（逆回転） | 全車共通の向き設定は確認済みのはず。1台だけ逆なら、モーターとESCの配線（ブラシモーターは2線の入れ替えで逆転）を教員と確認 |
| 4（ブレーキ後に逆回転する） | 故障ではなくESCの仕様（2章のクセ2）。Nを押せば止まる |
| 5（異音・異臭） | **すぐNを押して電源を切る**。ギアのかみ合わせ・異物・モーター過熱を点検。教員へ |

## 7. こんなときは（トラブル表）

| 症状 | 確認すること |
|---|---|
| 画面が「テストモード」 | pigpiod 未起動。`sudo systemctl start pigpiod` → プログラム再起動 |
| ピーピーが止まらない | pigpiod／ESCコネクタがGPIO12の列に刺さっているか／「テストモード」になっていないか |
| 学習中、いくら動かしても回り始めない | ホイールが浮いているか／バッテリー残量／ESC電源。動かせる範囲はN±1.5%まで。確認してもう一度。それでも反応がなければ教員へ |
| 後退の段階で、いくら待っても回らない | まれに切替が効かないことがある。いったん「中止」して、学習をもう一度最初から |
| 前進が勝手に止まった | 正常です（前進は10秒で自動停止） |

## 9. 全開点探索について（教員・基準車専用）

画面の「全開点探索」カードは、エンコーダを搭載した基準車でESCの全開位置（飽和点）を実測するための機能です。**学生車には不要で、通常の実習では使いません**。測定結果は全車共通の設定値として反映されます。

## 10. 終わりかた

1. 「● N」を押してタイヤが止まっていることを確認
2. カルテに記入したか確認（学習した日は特に）
3. ターミナルで Ctrl+C（プログラムはNを出してから終了。その後ESCが鳴き始めるのは正常）
4. ESCの電源を切り、バッテリーを外す
5. 車体をスタンドから降ろす
