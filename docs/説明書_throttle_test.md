# 説明書 — throttle_test.py（スロットル学習・接続テスト）

対象: 自動車整備専門学校 3年生
所要時間: フェーズ1（学習）約15分／フェーズ2（動作確認）約10分（1台あたり）
使うもの: 車両、車体スタンド（または台）、クロームブック、この説明書、個体値カルテ

---

## 0. 最初に読むこと【最重要】

**このプログラムはモーターを回します。** servo_test と違い、タイヤが回転します。

- 必ず **車体をスタンドに載せ、4輪すべてを床から浮かせてから** 操作すること
- 回転部（タイヤ・ギア・シャフト・ベルト）に **手・指・髪・ケーブルを絶対に近づけない** こと
- 万一に備えて、車の進行方向に人や物がないことも確認すること

プログラム側にも安全装置が入っています（前進・後退とも微速のみ・10秒で自動停止、後退前のブレーキは1秒で自動終了、学習モードの可動範囲制限、終了時は必ず停止信号）。**しかし安全装置はお守りではありません。ホイールを浮かせるのはあなたの仕事です。**

## 1. このテストでやること — 順番が大事

1. **フェーズ1: スロットル開度学習** — この車の「N・L点・D点・後退L点・R点」を測って保存する
2. **フェーズ2: 動作確認** — 学習した値で、「キックして動き出し、低速の信号で回り続けるか」を前進・後退それぞれでチェックする

**学習が先です。** 学習前の車は「どこからアクセルがつながるか」をプログラムが知らないため、前進ボタンを押しても回らないことがあります（実測で確認済みの現象です）。学習を済ませると、微速前進は本番と同じ「キック→低速」の信号を出すようになり、動作確認が意味を持ちます。

## 2. ESCの仕組み — ATのシフトレンジで考える

ESC（Electronic Speed Controller）は、**アクセルペダルとモーターの間にある電子制御ユニット** です。ラズパイからのPWM信号（%）を受け取り、モーターに流す電流を決めます。

信号の値とESCの反応は、ATのシフトレンジにたとえるとこうなります。

```
 後退側（低い%） ←――――――――――――――――――――――――→ 前進側（高い%）

 ――┼――――┼―――――――――――――――┼―――┼――――――┼――
   R点   後退L点  ← N(停止)ゾーン →  L点  D点      全開
   後退が  音が                      音が  前進が
   つながる 鳴る                     鳴る  つながる境界
   境界
```

- **Nゾーン**: この範囲の信号なら駆動がつながらず、タイヤは止まったまま。**Nは1点ではなく幅のあるゾーン** です（ESCが細かい信号の揺れを無視する「不感帯」のため）
- **L点**: ESCがモーターに電気を流し始める点。モーターから「ピー」と音が鳴りますが、力が足りず **タイヤはまだ回りません**
- **D点**: 止まった状態からタイヤが前進方向に回り始める点。L点より少し前進側にあります
- **後退L点**: 後退側で音が鳴り始める点。L点と左右対称の関係です
- **R点**: 止まった状態からタイヤが後退方向に回り始める点

**L点とD点のあいだが大事です。** モーターは動き出すときに一番力が要ります。だから止まった状態からはD点まで上げないと回りませんが、**一度回り始めれば、L点の近くまで下げても回り続けます**。本番プログラムはこの性質を使い、発進の一瞬だけD点の信号を出して動き出させ（発進キック）、そのあとL点とD点のあいだの弱い信号でゆっくり走ります。

そして重要なこと：**D点・R点・Nゾーンの幅は、ESCの個体ごとに違います**。だから車ごとに測って記録する必要があります。これが「スロットル学習」です。学習した値はこう使われます。

- **N は車ごとに決まった値で、学習では変えません**（設定に無い車は基準値の10.48%）→ 停止・待機はここ。ESCはこのNをニュートラルとして覚えるので（下のクセ4）、Nゾーンは必ずNを中心にできます
- **本番のアクセル** → **アクセル0%＝L点**。そこから前進側へ駆動を割り付ける（D点は約8%にあたる。車ごとに少し違う）。Nゾーンの「遊び」を飛ばすので、踏んだ分だけ必ず反応するアクセルになる
- L点を学習していない車は、アクセル0%＝D点になります。走れますが、D点より遅くは走れません

**知っておくべきESCのクセ4つ:**

1. **信号がないとピーピー鳴く**: 信号線に何も来ていないと警告音を出し続けます。プログラムを起動して信号が届くと止まります。つまり **「音が止まった＝配線と信号はOK」**。プログラム終了後にまた鳴くのは正常です
2. **ブレーキと後退は同じ側で、いきなり後退はできない**: R側の信号は、1回目は「ブレーキ」として扱われます。後退モードに入るには「R側 → N → もう一度R側」という順番が必要です（実車でRに入れる前に一度止まるのと同じ発想の安全仕様）。「微速後退」ボタンが最初に1秒のブレーキを入れてからNで待つのも、後退の学習開始時にプログラムが自動で「切替操作」を行うのも、この仕様のためです
3. **弱い信号ではモーターが「ピー」と鳴く**: L点を越えると、タイヤが回らないままモーターから連続した高い音が出ます。1のピーピー（途切れる警告音）とは別の音で、故障ではありません。**この音の鳴り始めがL点** です
4. **電源を入れた瞬間の信号を「ニュートラル」として覚える**: ESCは電源が入ったとき、そのとき届いている信号を停止位置として記憶します。L点・D点・R点は、すべてそこからの距離で決まります。だから **プログラムを起動してNを出してから、ESCの電源を入れる** こと。N以外の信号が出ているとき（タイヤを回している最中など）にESCの電源が入ると、ニュートラルがずれ、学習した点がすべて同じ量だけずれます。走行中にバッテリー電圧が下がってESCが再起動したときも同じです。**直し方は、● N の状態でESCの電源を入れ直すだけ** です

> **この車両構成の向きについて**: ヨコモ RD2.0 は実測により「高い%＝前進、低い%＝後退」です（D点はNより高い側）。ESCとモーターの組み合わせで決まるもので、全車共通のはずです。向きは `kuruma_settei.json` の `SUROTTORU_GYAKU` で決まります（RD2.0 は `false`）。画面の案内は、この設定に合わせて◀▶の向きを表示します。

## 3. 作業前チェックリスト

声に出して確認してください。

- [ ] **車体はスタンドの上、4輪すべてが床から浮いている**
- [ ] タイヤを手で回してみて、自由に回る（スタンドに接触していない）
- [ ] 回転部の近くに手・物・ケーブルがない
- [ ] バッテリーが接続されている
- [ ] **ESCの電源スイッチは、まだ切ってある**（プログラムを起動してから入れます。理由は2章のクセ4）

## 4. 起動のしかた

1. SSHでこの車のラズパイに接続する
2. `python3 throttle_test.py` を実行する（ターミナルに「N ○○% を出力中」と出る）
3. **そのあとで、ESCの電源スイッチを入れる**。起動音が鳴り、そのあと静かになれば配線と信号のチェック合格です（ピーピー鳴り続けるときは、信号が届いていません）
4. ブラウザで `http://（自分の車のIPアドレス）:8080` を開く
5. 「実機モード」表示を確認する

**ESCを先に入れてしまったときは、プログラムが起動した状態で、ESCの電源を入れ直してください。** この順番を守らないと、学習した値が次回ずれます。

## 5. フェーズ1: スロットル学習（案内つき）

学習はボタン1つで始まり、画面の案内に従って進めます。**出力を動かすのはあなた自身** なので、自分のペースでゆっくり探せます。仕事は「◀▶で少しずつ動かす → 変化が起きたら緑のボタンを押す」の繰り返しです（前進で2回、後退で2回。全部で4回）。

**周りを静かにしてから始めてください。** 前進も後退も、最初に探すのは「音」です。

### 手順

1. 「**スロットル開度学習開始**」を押す（確認が出るので、4輪が浮いていることを確かめてOK）
2. **［学習中 1/4: 前進（音が鳴り始める点）］** 「+0.01 ▶」を押して出力を少しずつ上げていく（最初は「+0.05 ▶▶」で近づけ、怪しくなったら +0.01 で刻むと速い）。モーターから **「ピー」と音が鳴り始めたら**「**音が鳴り始めた！**」を押す → L点が記録されます。**タイヤはまだ回りません**
3. **［学習中 2/4: 前進（タイヤが回り始める点）］** 出力はそのまま保たれます。続けて「+0.01 ▶」で上げていき、タイヤが **前進方向にじわっと回り始めたら**「**回り始めた！**」を押す → D点が記録されます
4. **［切替中］** プログラムが自動で後退モードへの切替を行います。**そのまま2秒ほど待つ**（タイヤがピクッと動くことがあります）
5. **［学習中 3/4: 後退（音が鳴り始める点）］** 今度は「◀ -0.01」で少しずつ下げていく。モーターから **「ピー」と音が鳴り始めたら**「**音が鳴り始めた！**」を押す → 後退L点が記録されます
6. **［学習中 4/4: 後退（タイヤが回り始める点）］** 続けて「◀ -0.01」で下げていき、**後退方向に回り始めたら**「**回り始めた！**」を押す → R点が記録されます
7. 4つの点が **`kuruma_settei.json` に保存** されて学習完了です。画面上部に「学習完了。保存しました」と出ます。**Nは変わりません**

**「保存しませんでした」と出たとき**: プログラムは学習結果から「ESCが覚えているニュートラル」（L点と後退L点の中間）を計算し、Nと0.10%以上ずれていたら保存しません。ESCがN以外の信号をニュートラルとして覚えている状態です。● N のまま **ESCの電源を入れ直し**、もう一度学習してください。

途中でやめたいときは「中止」（保存されません）。

緑のボタンは、段階が切り替わった直後の約1秒間は反応しません（二度押しで次の点まで記録されるのを防ぐため）。

**音がどうしても鳴らない車** は、音を探す段階（手順2・5）で「音が鳴らない車はここを押す」を押すと、その点をとばして次へ進みます。L点をとばした車はアクセル0%＝D点になり、低速では走れません。まず教員に確認してください。

### 保存される値

| 画面の表示 | `kuruma_settei.json` の項目 | 使われ方 |
|---|---|---|
| L点 | `ZENSHIN_SAITEI` | 本番: アクセル0%の信号 |
| D点 | `ZENSHIN_KYOKAI` | 本番: 発進キックの信号 |
| 後退L点 | `KOTAI_SAITEI` | このテストの「微速後退」で使う（本番では使わない） |
| R点 | `KOTAI_KYOKAI` | 本番: ブレーキの基準 |
| N | `THROTTLE_N` | 本番: 停止・待機の信号 |

L点は「NとD点のあいだ」、後退L点は「NとR点のあいだ」にあるときだけ保存されます。押し間違いでその外の値になったときは保存されず、ターミナルに注意が出ます。その場合は学習をもう一度行ってください。

### 学習結果の記入

画面の「N・L点・D点・後退L点・R点・停止ゾーン幅」をカルテに記入します。やり直したいときは「学習をやり直す」で学習した点をすべて消去して最初からできます。

> **探し方のコツ（L点・後退L点）**: 行き過ぎたと思ったら反対のボタンで戻し、「鳴らない↔鳴る」の境目を1〜2往復して確かめてから押すと正確です。

> **探し方のコツ（D点・R点）**: **必ず止まった状態から探すこと。** 一度回り始めたタイヤは、信号を弱めても回り続けます。行き過ぎたときは、タイヤが完全に止まるまで戻してから、もう一度 0.01 刻みでゆっくり探し直してください。回ったまま戻して押すと、D点（R点）がNに近い側へずれて記録され、本番で発進できなくなります。

> **なぜNを学習で変えないのか**: 以前は「N＝(D点＋R点)÷2」で毎回計算し直していました。ところがESCは、電源を入れた瞬間の信号（＝N）をニュートラルとして覚えます。学習でNを変えると、次に電源を入れたときESCのニュートラルも一緒に動き、せっかく測ったL点・D点・R点が全部ずれてしまいます。教員車の実測では、Nを10.30%から10.57%に変えて電源を入れ直すと、L点は10.63%から10.91%へ動きました（どちらも「Nの約0.33%前進側」）。**基準を動かさないことが、測定の再現性の前提** です。

## 6. フェーズ2: 動作確認（合否チェック 6項目）

学習が終わったら、「スロットル操作」のボタンで **微速前進 → 微速後退** の順に動作を確認します。ここで確かめるのは、**本番と同じ「キック→低速」でタイヤが回り続けるか** です。

### ボタンの動き

- **▲ 微速前進**: D点の信号を一瞬だけ出して動き出させ（**キック**）、そのあと本番と同じ低速の信号（L点＋ACCEL_SAIDAI分）まで下げます。10秒で自動的にNへ戻ります
- **▼ 微速後退**: ①ブレーキ1秒 → ②Nで1秒待つ（後退モードへ切替）→ ③R点でキック → 低速の信号、の順に自動で進みます。10秒で自動的にNへ戻ります。最初にブレーキが入るのはESCの仕様（2章のクセ2）で、**前進中に押せばブレーキの確認になります**
- **● N（停止）**: いつでも止まります。キックや切替の途中でも、押せばそこで打ち切ります

実際に出す信号の値は、ボタンの下に表示されます（例: 「キック 10.86% を0.3秒 → 低速 10.74%」）。進み具合は画面上部に表示されます。キックの時間は `kuruma_settei.json` の `KICK_BYO`、低速の強さは `ACCEL_SAIDAI` で、本番と同じ値を使います。安全のため、低速の信号は「D点（R点）から0.20%」を上限にしています。

### 合否チェック

| # | 確認項目 | やり方 | 合格基準 |
|---|---|---|---|
| 1 | Nで止まる | 「● N（停止）」を押し、手でタイヤを軽く回す | 止まっている・ブレーキの抵抗もない・音も鳴っていない |
| 2 | 前進でキックして動き出す | 「▲ 微速前進」を押す | 押した直後にタイヤが前進方向に回り始める |
| 3 | **前進の低速で回り続ける** | そのまま10秒見る | キックが終わって低速の信号に下がったあとも、**止まらずに回り続ける** |
| 4 | ブレーキが効く | 前進中に「▼ 微速後退」を押す | 惰性より明らかに早く止まる |
| 5 | **後退でもキックして低速で回り続ける** | 4のあと、そのまま見る | 約2秒後に後退方向に回り始め、低速の信号に下がったあとも回り続ける |
| 6 | 異音・異臭がない | 回転中に耳と鼻で確認 | ガリガリ音・焦げ臭さがない（低速の「ピー」という音は正常） |

**不合格だったときの見かた**

| 不合格項目 | 原因の候補と対処 |
|---|---|
| 1（じわ回りする／音が鳴る） | 学習をやり直す。じわ回りの向きに注目（前進方向ならD点のボタンを押すのが早すぎ、後退方向ならR点が早すぎ） |
| 2（キックしても動き出さない） | D点が低く記録されている（回ったまま戻して押した）。学習をやり直し、止まった状態から探す。バッテリー残量／ESC電源スイッチも確認 |
| 3・5（低速に下がると止まる） | `kuruma_settei.json` の `ACCEL_SAIDAI` を1ずつ上げて、もう一度確認する。**ここで止まる車は、本番でも走行中に止まります**。動き出す前に下がってしまう車は `KICK_BYO` を0.1ずつ長くする |
| 逆回転する | 全車共通の向き設定は確認済みのはず。1台だけ逆なら、モーターとESCの配線（ブラシモーターは2線の入れ替えで逆転）を教員と確認 |
| 5（後退しない） | まれに後退モードへの切替が効かないことがある。「● N」を押してから、もう一度「▼ 微速後退」 |
| 6（異音・異臭） | **すぐNを押して電源を切る**。ギアのかみ合わせ・異物・モーター過熱を点検。教員へ |

> **スタンドの上と床の上は違います。** タイヤを浮かせた状態は、床を走るより軽い力で回ります。ここで合格しても、走行では止まることがあります。その場合は ACCEL_SAIDAI を1ずつ上げてください。逆に、ここで止まる設定は、床の上ではまず走れません。

## 7. こんなときは（トラブル表）

| 症状 | 確認すること |
|---|---|
| 画面が「テストモード」 | pigpiod 未起動。`sudo systemctl start pigpiod` → プログラム再起動 |
| ピーピーが止まらない | pigpiod／ESCコネクタがGPIO12の列に刺さっているか／「テストモード」になっていないか |
| 「保存しませんでした: ESCのニュートラルが…ずれています」と出る | ESCがN以外の信号をニュートラルとして覚えている。● N の状態でESCの電源を入れ直し、もう一度学習する |
| 前回は合格した設定なのに、急に速い／キックしても動かない | ESCのニュートラルがずれた可能性が高い（電源を入れる順番、走行中のESC再起動）。● N の状態でESCの電源を入れ直す。直らなければ学習し直す |
| 音が聞こえない | 周りを静かにする。耳をモーターに近づける（**回転部に顔や髪を近づけすぎない**）。バッテリー残量を確認。それでも鳴らなければ教員へ |
| 音が鳴る前にタイヤが回り始めた | 「中止」して最初から。上げる刻みを +0.01 にして、ゆっくり探す |
| 学習中、いくら動かしても回り始めない | ホイールが浮いているか／バッテリー残量／ESC電源。動かせる範囲はN±1.5%まで。確認してもう一度。それでも反応がなければ教員へ |
| 後退の段階で、いくら待っても回らない | まれに切替が効かないことがある。いったん「中止」して、学習をもう一度最初から |
| 前進・後退が勝手に止まった | 10秒ちょうどで止まったなら正常です（自動停止）。それより早く止まったなら、低速の信号が弱すぎます（6章の不合格項目3・5） |

## 9. 全開点探索について（教員・基準車専用）

画面の「全開点探索」カードは、エンコーダを搭載した基準車でESCの全開位置（飽和点）を実測するための機能です。**学生車には不要で、通常の実習では使いません**。測定結果は全車共通の設定値として反映されます。

## 10. 終わりかた

1. 「● N」を押してタイヤが止まっていることを確認
2. カルテに記入したか確認（学習した日は特に）
3. ターミナルで Ctrl+C（プログラムはNを出してから終了。その後ESCが鳴き始めるのは正常）
4. ESCの電源を切り、バッテリーを外す
5. 車体をスタンドから降ろす
